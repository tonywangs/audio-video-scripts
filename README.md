# audio-video-scripts

Audio and video editing, timing, and loudness.


Independent utilities collected into one private repository. Each lives under `tools/<name>/`; run its installation and commands from that directory. This is a source consolidation, not a unified application.

Original repositories and server workspaces were retained. Original histories are reachable through merge commits and `history/` tags. Unpublished source was copied from the server; it may be incomplete.

- [audio-excerpt-desk](tools/audio-excerpt-desk/README.md): A local audio workbench for selecting, auditioning, and exporting named excerpts with precise source references.
- [video-excerpt-desk](tools/video-excerpt-desk/README.md): A local video workbench for previewing, naming, and exporting accurately bounded clips with saved selections and traceable source references.
- [subtitle-sync-desk](tools/subtitle-sync-desk/README.md): A local subtitle-timing workbench for correcting offset and drift against video, previewing changes, and exporting reusable subtitle files.
- [audio-loudness-desk](tools/audio-loudness-desk/README.md): A local audio workbench for comparing recording loudness, auditioning normalized copies, and exporting independently checked audio with traceable settings.
